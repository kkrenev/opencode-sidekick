# Changelog

## Unreleased

- Added a test suite: Vitest covers the message map, stream deltas, the composer palette, the formatters and attachment limits, plus the composer, chat header, tab menu and attachment tray in jsdom; `@vscode/test-electron` smoke-activates the extension and checks its commands and view container. `npm test` runs the unit gate, and GitHub Actions runs architecture, compile, unit tests, package and the smoke job on every push and pull request.

- The panel now survives a server restart without a Reload: a dropped event stream reconnects on its own with an exponential backoff (1s doubling up to 30s with ±25% jitter), resubscribes and drops frames the server replays by their envelope id. A restarted server on a new port or with a new password is picked up from the rewritten `service.json`, and the offline banner appears only when `GET /api/info` is down too, so a transient drop no longer flashes it or raises a notification. A message the server never received keeps its draft and chips, and the new **Resend** button repeats exactly that send; a rejected 409/404 request is not offered for a repeat.

- Tool cards now work as a place to act: the title of a `read`/`write` card opens the file, an `edit` opens a `vscode.diff` of its before and after text with **Open file** beside it, and a shell card shows the full command, exit code and duration with **Copy command** and **Open terminal**. Status chips read **Queued** / **Running** / **Done** / **Error** (a completed call keeps the internal `ok` state), and output longer than 200 lines collapses behind **Show full (N lines)** / **Show less** with a hidden-lines note (expanding stops at 200k characters), so a 10k-line result opens instantly while the transcript search still scans the whole output and expands the window on a jump.
- Find in the chat with `Cmd/Ctrl+F`: a find bar over the transcript counts `N/M`, `Enter` / `Shift+Enter` (or the arrows) cycle matches, `Escape` closes it, and matches are highlighted in message text, reasoning and tool names or titles. A jump opens a collapsed reasoning block or tool body and scrolls the match itself into view, tool input and output are searchable behind an off-by-default **Output** toggle, the bar sits in the layout flow instead of covering the transcript, and a jump reaches messages outside the virtual window without fighting auto-scroll.
- Replaced the single-session header pill with session tabs: open sessions from history or the `+` button, switch with `Cmd/Ctrl+1..9`, close with `Cmd/Ctrl+W` or a middle click.
- Open tabs and the active session are persisted per workspace, sessions deleted on the server are marked missing, and running tabs show a live indicator.
- Each tab keeps its own composer draft, caret, transcript scroll position, expanded reasoning/tool blocks, and model/effort/mode through a host-backed `SessionRuntime`; typing in a new unsaved chat carries over when the session is created.
- Added attachments to the composer: a `+` menu with File, Folder, Selection, Screenshot and Problems, drag and drop, pasted images with 64px previews, per-item removal, a 10 attachment / 10 MB limit, and `Cmd/Ctrl+Shift+A` to open the menu. Screenshot captures a region with `screencapture` on macOS and asks you to paste from the clipboard on Windows/Linux; `OpenCode: Attach Screenshot` and `OpenCode: Attach Selection` do the same from the command palette, and a selection arrives as the source file with a `?start&end` range (or inline text for virtual and non-plaintext documents) plus its `path:start-end`. Attachments are sent as `file://` URIs, kept per session, cleared after send, and image previews are served from `globalStorageUri`.
- Attachments now show up in the transcript: a screenshot or image renders inline with a click-to-zoom lightbox and **Open in editor**, any other file becomes a chip with its name, relative path and **Open**, and a `read`/`write`/`edit` tool card opens the file it touched at the reported line. Inline `data:` images are capped at 1.5 MB, so a huge payload degrades to a named placeholder instead of a megabyte frame, and a file outside the workspace or already deleted gives a warning instead of a broken tab.
- Long sessions now paginate with `GET /api/session/{id}/message` cursors: the panel opens a 2000-message session from a single page with a constant number of rendered messages, loads older pages when you scroll up without moving the text under the cursor, shows a `Jump to latest` button, and refreshes only the tail on tool and step events instead of reloading the whole transcript. Loaded tabs restore their reading position by distance from the bottom.
- Multi-root workspaces keep a separate chat per folder: the header gains a folder picker, every session, model, agent, command, skill and file-search request uses the selected folder, tabs and the active tab are remembered per folder, and the previous `{ directory, open, active }` state migrates to the per-folder shape. The editor picks the folder until you choose one by hand or a turn is running, and a new chat draft is kept per folder.
- Right-click a tab for its own menu: Rename in place, Pin/Unpin, Archive, Fork, Copy session ID and Delete with an inline confirmation. Pinned tabs stay at the front of the strip and refuse close, `Cmd/Ctrl+W` and middle click until you unpin them, rename shows up in the tab and the history at once, and a fork opens as a separate session.
- Copy messages from a hover button or the message menu, with `Copied` feedback and no role heading; `OpenCode: Copy Last Answer`, `Copy Conversation as Markdown` and `Copy Selection with Reference` export markdown with roles, code fences and one line per tool call (no tool output or reasoning), truncating huge sessions at 5 MB. Pasting more than 8000 characters keeps the text in the composer and offers to attach it as a `pasted-*.txt` file, and native paste shortcuts still work.
- Added a context meter to the composer: the chip shows the used percentage of the model's context window, the tooltip adds used/limit, cumulative in/out/cache tokens and session cost, and models without a reported limit fall back to a plain token count. At `contextWarnPercent` (80% by default) a **Compact** button appears; at `contextCompactPercent` (95%) the active session compacts automatically, once per high-usage episode. While a compaction runs the chip reads `Compacting…`, a system plaque lands after the transcript, and the compaction timestamp is persisted per session so a reload still shows `—` until the next turn.
- A finished turn now ends with a **Review** card (`N files · +A −D`): it opens a singleton diff panel with collapsible files, ± highlighting, Prev/Next across loaded turns, Copy patch, and click-to-open at the first changed line. The card also appears for failed and interrupted turns; patches stay out of the chat snapshot, steering messages of one turn collapse into a single entry, and oversized patches are capped at 8 MB / 4000 lines with a visible truncation note.
- **Undo** on the turn card and in the message menu of the last user message: a confirmation lists the files of that turn first, then the files go back to the state before it. The card that follows offers **Keep** (drop the turn and leave a plaque) or **Undo revert** (files and turn come back). Only the last turn can be undone, a staged revert blocks Send and Compact, and the card survives a window reload.
- Permission requests are answered in the panel: a pinned card above the revert card shows the tool, file or command with a risk chip and offers **Allow once**, **Always allow** (stores a project rule, only when the request has one) and **Reject** with an optional reason. A request answered in another client or expired disappears, hidden tabs show a pending count, and Settings gains an off-by-default auto-approve toggle for `read`, `glob`, `grep`, `list` and `find` plus a list of saved rules with delete.
- Messages sent while the agent works now wait in the server's session inbox instead of blocking the composer. A strip above the composer lists them with **Send now** (`steer`), **Edit** (cancel and put the text back) and **Delete**, and the composer chip reads `N in queue`. The queue survives tab switches and reloads, three messages sent in a row run in order, `opencodeSidekick.queueDelivery` chooses `queue` (default) or `steer`, and a staged revert blocks Undo until the queue is empty.
- Editor context comes to the composer: right-click a file or an editor tab for **Add File to Chat**, **Add Selection to Chat** and **Add Problems to Chat** (also in the palette). A file and a selection arrive as chips and are sent as `files[]` with an `@path` or `@path:start-end` mention; a selection carries exactly the selected lines, a Problems attachment is one chip with the diagnostic count (capped at 200 lines in the body). `opencodeSidekick.autoAttachActiveFile` (off by default) keeps the active workspace file attached as an automatic chip that never duplicates a manual one and stays dismissed until you switch files.
- The chat can be opened as an editor tab beside the code with `OpenCode: Open Chat in Editor Tab` or **Open in editor tab** in a tab's context menu. It is a single tab that follows the active session, shows the session title and a running/attention/idle icon, shares the transcript with the sidebar in both directions (attachments get a preview in each webview, and removing a chip clears it in both surfaces), and closing it keeps the session. A window reload restores the tab on its last session.
- Notifications when you look away: a turn that finishes while its chat is not on screen raises a system notification with **Open** (`failed` uses an error notification, a pending permission asks for approval), the OpenCode view badge counts chats with a new reply or a waiting request, and the badge clears when you open or focus that chat. `opencodeSidekick.notifications` picks `all` / `errors` / `off` and `opencodeSidekick.notifyOnlyWhenHidden` (on by default) keeps quiet while the chat is on screen; a dropped event stream now shows the banner with **Retry** and notifies once instead of staying silently "connected".

## 1.2.0

- Rebuilt the webview on React 19 with an esbuild bundle, without changing the existing session, streaming, command or mention behavior.
- Added a full settings drawer with a header gear button, menu item and `OpenCode: Open Sidekick Settings` command.
- Added new-session defaults for model, effort and mode. Server defaults are shown in the composer when a session has no explicit selection.
- Added composer, transcript, appearance and server settings: send key, auto-scroll, timestamps, reasoning visibility, compact tools, accent, density, font size, CLI path and auto-start.
- Settings apply immediately and are persisted through VS Code configuration; changing a model, effort, mode or setting no longer resets the composer draft or reloads the webview.
- Refreshed the panel visual design with settings sections, accent themes, density modes, cleaner popovers and a narrower-sidebar layout.
- Added tests covering defaults, draft preservation, settings updates and narrow layout.

## 1.1.0

- Searchable model picker with provider, id and name filtering.
- Effort picker backed by the model's variants, including `Default`.
- Mode picker for the server's primary agents, with subagents kept out of the session switcher.
- Slash command palette with local panel commands and every command reported by the server.
- `@` mention palette for files and skills, with keyboard navigation and prompt attachments.
- Fixed the header `...` menu opening off-screen.
- Fixed model, agent, command, skill and file-search requests to send the workspace as `location[directory]`.
- Session model and agent are refreshed immediately after a change.

## 1.0.0

- First release.
- OpenCode docked as a webview in the VS Code secondary sidebar.
- Native chat UI built on the OpenCode HTTP API and event stream: streamed markdown, collapsible reasoning, tool cards with live status, and code blocks with copy.
- Session history grouped by day, with search, switching and delete.
- New sessions, model picker and agent picker in the panel.
- Reliable typing and paste in the composer, `Enter` to send, `Shift+Enter` for a new line.
- Automatic connection to the local OpenCode server, including starting it when needed.
- Commands to focus the panel, start a session, open history, reload, open the UI in a browser, and fall back to the integrated terminal.
